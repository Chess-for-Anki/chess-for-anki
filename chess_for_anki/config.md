Use **Chess for Anki → Settings** to select the next training level, enable the first-view demonstration, and control piece sounds.

The card has **Voice on/off**, **Voice speed** and **Demo on first view** controls. Narration defaults to 1.5× and can be changed from 0.5× to 2×. **Language packs** selects the basic system language or an optional natural voice ZIP. The add-on does not create cards or install voice recordings automatically.
