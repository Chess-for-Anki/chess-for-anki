# Chess notation

Choose English or Portuguese in Settings under Chess notation language. Follow commentary language uses the selected language pack.

| Piece | English | Portuguese |
| --- | --- | --- |
| King / Rei | K | R |
| Queen / Dama | Q | D |
| Rook / Torre | R | T |
| Bishop / Bispo | B | B |
| Knight / Cavalo | N | C |
| Pawn / Peão | No initial | Sem inicial |

Captures use x, with the pawn's origin file included, such as exd5. Displayed castling uses 0-0 or 0-0-0. Check uses + and checkmate uses #. Promotions use an equals sign followed by the chosen piece, such as e8=Q in English and e8=D in Portuguese. Disambiguating origin files or ranks remain part of the move, for example Rae1 / Tae1. En passant can be annotated with e.p. after the move.

Piece initials apply to all non-pawn pieces. Dama is the Portuguese notation name for the queen. This display uses # for checkmate consistently. In queenside castling the rook moves three squares and the king moves two squares. Engine moves and imported/exported PGN retain English SAN, with O-O / O-O-O internally.
