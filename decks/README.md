# Free decks

Download the `.apkg` file and open it in Anki, or use **File > Import**.

- **[Foundations - 30 cards](https://github.com/fernandomec/chess-for-anki-community/raw/refs/heads/downloads/decks/Chess-for-Anki-Foundations.apkg):** simple opening plans, Scholar's Mate and its defence, basic mates and promotion.
- **[Starter - 60 cards](https://github.com/fernandomec/chess-for-anki-community/raw/refs/heads/downloads/decks/Chess-for-Anki-Starter.apkg):** the earlier free collection, with reviewed commentary.

These files contain no personal review history. Paired perspectives count as separate cards. Use the [Chess for Anki add-on](https://github.com/fernandomec/chess-for-anki-community/releases/tag/v1.4.2-preview) for the interactive board.
